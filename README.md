# voxel-snake-lwjgl

Minecraft-like 3D voxel snake game in Java with LWJGL and Gradle. Includes procedural world and textures plus Tab world-edit mode.

Русский перевод:

# voxel-snake-lwjgl

Minecraft-подобная 3D-игра про змею из блоков на Java с LWJGL и Gradle. Включает процедурно генерируемый мир, текстуры и режим редактирования мира через клавишу Tab.
